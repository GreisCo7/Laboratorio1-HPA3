Este repositorio contiene las tres primeras prácticas desarrolladas en C# utilizando Windows Forms (.NET Framework). 

### Estructura del Repositorio

### - Práctica #1: Control de Fechas (Pract1-Controles-Nuevo)

* **Descripción:** Interfaz gráfica para ingresar valores numéricos correspondientes a Día, Mes y Año. Valida que los campos no estén vacíos y concatena los datos mostrándolos en un formato de fecha legible en pantalla.
* **Componentes clave:** TextBox, Label, Button, y uso de funciones de texto 

### - Práctica #2: Cálculo de Descuentos (Descuentos)

* **Descripción:** Programa encargado de calcular diferentes porcentajes de descuento aplicados a una venta dependiendo del rango del monto ingresado (10%, 20%, 30% o sin descuento).
* **Componentes clave:** Estructuras condicionales anidadas (if - else if), operadores lógicos (&&) y conversiones numéricas con precisión monetaria

### - Práctica #3: Calculadora Estructural (Pract8-Estructuralf)

* **Descripción:** Formulario que funciona como una calculadora aritmética básica agrupada dentro de un contenedor. El símbolo de operación matemática cambia dinámicamente según la opción de botón radial seleccionada por el usuario.
* **Componentes clave:** GroupBox, RadioButton con eventos CheckedChanged, y manejo de excepciones matemáticas
